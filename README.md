# FCG Dev Hub · интерактивные прототипы

Два интерфейса для обсуждения логики с командой:

- **Сайт:** [index.html](./index.html)
- **Telegram-чат:** [bot.html](./bot.html)

## Сайт

Реестр таблицей и карточками; фильтры по отделу, типу, сотруднику и статусу; «Мои разработки»; карточки во всплывающих окнах; смена статуса в таблице за три клика; ссылки на продукты; история и комментарии к разработкам.

Выгрузки: весь бэклог в настоящем XLSX и Markdown; список заполненных ссылок в CSV; исходные записи в JSON.

## Telegram-прототип

/start → регистрация → демонстрационное подтверждение Дмитрием → /new → название, описание до 200 символов, аудитория, результат, статус, отдел, дата вручную, вид → предпросмотр → сохранение.

Для «Реализовано» обязательна ссылка. /mydiv показывает свои разработки и позволяет обновить статус. Уведомления о смене статуса с сайта появляются в личном чате и AI-группе. Сообщения оформлены карточками с переходами в реестр.

## Правки к интерфейсу

На обоих прототипах: «Оставить правку» → выбрать элемент → комментарий. В «Правках» доступны удаление и общий ZIP с Markdown и JSON. Замечания сайта и бота хранятся отдельно.

Сохраняются раздел, выбранный элемент, его текст, CSS-селектор, автор и комментарий. Нет автоматической привязки к строкам исходного кода, снимков экрана или отправки заданий разработчику.

## Важно для демонстрации

Это статические прототипы. Нет реальной авторизации, Telegram-бота, подключения Аспро или серверной базы. Сотрудники FCG указаны для демонстрации; назначения и продукты вымышлены.

Данные и правки сохраняются **только в текущем браузере и на текущем адресе сайта**. Разные пользователи и устройства не видят изменения друг друга. Публикация на GitHub Pages не переносит замечания с localhost и не создаёт общую базу правок. Чтобы передать замечания, скачайте ZIP в браузере, где их оставляли.

Сайт и бот, открытые с одного опубликованного адреса в одном браузере, используют общий локальный реестр. Между ними работает локальная синхронизация событий. Отдельные скачанные HTML-файлы могут иметь раздельное хранилище.

## Запуск

Установка и сборка не нужны. Для локального запуска:

```sh
python3 -m http.server 8765
```

Откройте `http://localhost:8765/` и `http://localhost:8765/bot.html`.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root). После публикации сайт доступен по корневой ссылке Pages, чат — по той же ссылке с `bot.html`.

Используются только локальные HTML/CSS/JavaScript. Внешние библиотеки, API-ключи и облачные сервисы не требуются.
